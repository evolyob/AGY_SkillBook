# Phase 2 Protocol: Systematic Data Collection

## Objective
Perform systematic extraction, filtering, and structured collection of data from user-provided files, internal documents, or specified knowledge sources.

## Core Rules
1. **Scope Alignment**: Extract only information directly relevant to the scope established in Phase 1.
2. **Multi-Source Tagging**: Label extracted data points with their source origins (e.g., Department A, Spec Section 3.1, Meeting Minutes 2026-07).
3. **Categorization**: Group data into:
   - Primary Baseline (Core Requirements / Critical Specs)
   - Secondary / Generality Requirements (Cross-department extensions)
   - Unresolved / Conflicting Statements
