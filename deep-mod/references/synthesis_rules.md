# Phase 4 Protocol: Synthesis, Gap Analysis & Visual Review Delivery

## Objective
Synthesize research findings or render surgical review deliverables based on the selected execution track.

## Delivery Branches

### Branch 1: Deep Research Synthesis & Gap Audit
1. **Traceability Mapping**: Map core requirements 1-to-1 against specifications or execution plans.
2. **Scenario Stress-Testing**: Test happy path and 3–5 exception edge-cases.
3. **Gap Matrix Generation**: Output a structured table:
   - Item ID | Requirement Type | Specification Status | Gap & Risk Description | Actionable Advice
4. **Report Output**: Write final report to `~/agy/download/` with UTF-8 BOM encoding.

### Branch 2: Engineering & Architecture Review
Reference `references/visual_archetypes.md` and auto-route to sub-tracks:
- **B1 (Explore)**: Render topology, sequence, directory tree, or pseudocode.
- **B2 (Diff)**: Render Before/After minimal-diff and drop-in replacement snippet.
- **B3 (Explain)**: Render visual aid and 3~5 sentence walkthrough.
Write final deliverable to `~/agy/download/` with UTF-8 BOM encoding.
